# DSC 0.1.5

**发布日期**：2026-11-26　|　**前一版**：[v0.1.4](https://github.com/Rcyc-1025/DSC/releases/tag/v0.1.4)　|　**许可证**：Apache-2.0

这一版修好了 **安卓切到问答模式后再也回不到聊天模式** 的死锁，并让「模式」的切换在重启后保持住。

## 这次修了什么

**① 问答模式把整条底部导航藏起来了。** 底栏原本只在聊天模式显示，而切换模式的唯一入口是设置页的「模式」行——
底栏一消失就进不去设置，问答会话列表页又没有设置入口，于是「问答 → 聊天」这条路彻底断了。
现在主界面一律保留底栏：问答模式下三格是「我 / 设置 / 会话」，点「会话」回到多会话列表，
点「设置」就是问答模式的设置页（副标题「问答模式的设置」、右上按钮「会话」），切回聊天后底栏变回「我 / 设置 / 聊天」。

**② 核心层也不让在问答模式下切栏。** 即使底栏显示出来，`dsc_router_set_tab()` 对非聊天模式一律返回
`DSC_E_STATE`，点了也没反应。这次在 `src/core/router.c` 里加了问答模式分支：`QA_READY / QA_LIST / QA_THREAD / QA_TAB`
都接受切栏，切到「会话」回列表，切到「我 / 设置」进入新状态 `QA_TAB`，返回键从 `QA_TAB` 退回列表。
桌面端 `dsc_app.c` 同步渲染，两个平台行为一致。

**③ 模式切换重启后回滚。** `dsc_router_switch_mode()` 切完模式没有写 `ui.default_mode`，而启动时正是按它分流，
于是「切到问答 → 重启 → 又回到聊天」。现在切换成功即写库（`chat` / `qa`），重启保持上次选中的模式。

## 签名

- Windows 产物**未做代码签名**（本机没有 `signtool`）；首次运行若被 SmartScreen 拦，选「更多信息 → 仍要运行」，或用上面的 SHA-256 自行核对。
- Android APK 用固定调试证书签名（SHA-256 `55e55bc6…`），与 0.1.2 / 0.1.3 / 0.1.4 相同，因此**可以直接覆盖升级**。
  从 0.1.1 及更早版本升级仍需先卸载旧版（证书不同）。
