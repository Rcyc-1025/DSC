### 4.3 按修订版补齐的实现

修订版的模块清单仍要求 PerfMonitor 提供 `sample` / `report` / `assert_budget` 三项，而动效与回归那节被删后，采样接口在旧实现里只剩 `report`（预算表）与 `assert_budget`（超标判定），`sample` 缺失。本轮补齐：

- `src/core/perf.h` / `perf.c`：新增 `aic_perf_sample` 结构（时间、常驻内存、单帧耗时与预算、模式/三栏切换耗时、库与 WAL 字节数、存储分项）与 `aic_perf_sample_init` / `aic_perf_sample_take` / `aic_perf_sample_set_frame` / `aic_perf_sample_set_switch` / `aic_perf_sample_json`，以及 32 槽内存环形缓冲（`aic_perf_ring_reset/push/count/avg_kb/peak_kb`）与常量 `AIC_PERF_FRAME_BUDGET_MS = 16.7`。
- `src/cli/aic_cli.c`：新增 `aic.exe perf` 子命令，打印采样 JSON，供人工或 CI 看内存曲线与存储分项。
- 测试：`test_core.c` 的 test_perf 与 `aic_verify.c` 的 FR-24 各增一组采样断言（默认帧预算、超 16.7ms 被标记、存储分项按 KB 换算、JSON 可解析且字段与采样一致）。
