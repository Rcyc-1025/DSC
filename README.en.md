# AIChat — a companion chat client in pure C

A **pure C** local companion chat client for Windows desktop (Win32 + GDI) and Android. You bring your own DeepSeek API key; no third-party server sits in between.

中文说明见 [README.md](README.md)。

- Two modes: **Q&A mode** (multiple threads, list/search/pin/delete) and **Chat mode** (one single companion thread, QQ-style three-tab layout: Me / Settings / Chat)
- Companionship persona with prompt versioning, plus user-profile variables injected into prompts
- Conversation export/import as JSON with checksum and three conflict policies
- Plugins as native shared libraries (Windows DLL / Android `.so`, plain C ABI) that run in a separate process, so a crash cannot take the app down
- Update flow: manifest → download → hash/signature check → mandatory backup → migration with rollback
- Performance budgets you can measure: cold start, idle memory, mode switch, tab switch, paging and export over 10k messages

Implementation-level design is in `docs/DESIGN.md`; the requirement-by-requirement matrix is generated by `aic.exe verify` into `docs/FR-MATRIX.md`.

## Build

Requirements: Windows 10/11 x64 with a MinGW-w64 (MSYS2 ucrt64) toolchain. No MSVC, no CMake, and no interpreter runtime is needed by the shipped binaries.

```powershell
# Unit tests (also builds the plugin host and the test plugin DLLs)
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Target test
.\build\test_core.exe

# Command-line verifier
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Target cli
.\build\aic.exe verify . build\verify

# Desktop client
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Target gui
.\build\AIChat.exe
```

Default flags are `-std=c11 -O2 -Wall -Wextra`, currently with zero warnings.

## Verification

- `aic.exe verify` — checks FR-01 through FR-24, prints a table, writes `docs/FR-MATRIX.md`; the exit code is the number of failed checks.
- `aic.exe bench` — paging/export over 10k messages plus idle memory; writes `build\bench\bench-report.md`.
- `aic.exe perf` — one performance sample (memory, frame cost, storage breakdown) as JSON.
- `aic.exe doctor` — database, credential store and plugin host self-check.
- `build\test_core.exe` — core unit tests (PASS/FAIL per case, summary at the end).

The UI is reviewed with off-screen rendering, so no live desktop is required:

```powershell
python tools\shots.py
```

This renders eight PNGs into `build\shots`: chat, me, settings, Q&A, guide, AI info, first-run wizard and a narrow window.

Pre-commit scan (sensitive strings, license, headers, oversized files, binary contamination):

```powershell
python tools\precommit_scan.py
```

## Android

Requirements: Android SDK (build-tools 37.0.0 + platforms/android-35), NDK r27c, JDK 21. **No Gradle** — the script packs with javac + d8 + aapt2 + zipalign + apksigner.

```powershell
python tools\build_android.py     # build_android\AIChat.apk (arm64-v8a, v2/v3 self-signed)
python tools\verify_android.py    # APK structure / ABI / manifest / signature, 18 assertions
```

## Windows packages

```powershell
python tools\package_win.py       # dist\AIChat-1.0.0-win-x64-portable.zip (+ .sha256)
python tools\build_arm64.py       # cross-compile Windows ARM64 artifacts into build\arm64\
python tools\package_win.py --arm64 # dist\AIChat-1.0.0-win-arm64-portable.zip
python tools\make_installer.py    # dist\AIChat-1.0.0-win-x64-setup.exe (+ .sha256)
```

The portable zip unpacks and runs; it contains the GUI, the CLI, the sample plugin, the docs and `install.ps1` (creates a Start-menu shortcut without admin rights). The installer is self-extracting, installs to `%LOCALAPPDATA%\Programs\AIChat` by default, supports `/S` and `/D=<dir>`, and ships a matching silent uninstaller.

## Status

All 24 requirements have automated checks that pass (578 unit tests + 254 requirement assertions).

Deliberate scope limits, by decision of the requirement owner:

- The network layer stops at request assembly, stream parsing and error classification. The default transport returns "no transport configured" instead of pretending to reach the network, and the in-app chat demo is produced by a local offline transport.
- The Android APK compiles, signs and verifies, but has not been run on a real device.
- The update flow stops at download + verification; no install action is performed.
- Windows binaries are unsigned (no `signtool`/certificate on the build machine); the Android APK uses a self-signed key.
- Windows ARM64 artifacts are cross-compiled (`AIChat-1.0.0-win-arm64-portable.zip`) but **not verified on ARM64 hardware** — the build machine is x64 and cannot execute ARM64 binaries. No ARM64 installer (portable zip only).

See section 9 of `docs/PRE-RELEASE-EVIDENCE.md` for the complete list.

## Data and privacy

- The API key lives only in the OS credential store (Windows Credential Manager / Android Keystore-backed storage); neither the UI nor logs show it, and exports never contain credentials.
- Conversation data stays in the app-private directory (`%LOCALAPPDATA%\AIChat`; portable mode honours `AICHAT_DATA_DIR`).
- Requests go directly to the model endpoint you configure. This project collects nothing.
